## Part A: Airless Spray Application

### 1. Spray Tip Selection by Surface

Tip code system: First digit x 2 = fan width (inches at 12" distance). Last two digits = orifice diameter in thousandths of an inch. Example: 517 = 10" fan, 0.017" orifice.

| Substrate Type | Tip Orifice | Common Tip Codes | Typical Material |
|---------------|-------------|-----------------|-----------------|
| Lap siding (wood/fiber cement) | 0.015-0.019" | 515, 517, 617 | Acrylic latex |
| Fascia and eaves | 0.013-0.015" | 413, 515 | Acrylic latex |
| Exterior trim and casings | 0.011-0.013" | 211, 311, 313 | Waterborne enamels |
| Stucco and rough masonry | 0.017-0.021" | 517, 619, 621 | High-build acrylics |
| CMU block filler | 0.025-0.035" | 527, 531, 535 | Heavy block fillers |
| Shingles and shakes | 0.013-0.015" | 413, 415 | Solid color stains |
| Metal doors and gutters | 0.010-0.014" | 310, 412 | DTM coatings |

**Tip wear**: Replace when fan width decreases by 25%. Latex coatings: replacement interval typically 15-40 gallons.

### 2. Pressure Settings (PSI)

| Application | PSI Range | Notes |
|------------|-----------|-------|
| Standard exterior latex | 1,500-2,500 | Adjust to eliminate "tails" at spray pattern edges |
| Block fillers / elastomerics | 2,300-3,000 | Heavy-duty tip required (0.028"+) |
| Fine finish / LP tips | 50% lower than standard | Reduces bounce-back and overspray; extends pump/tip life |

**Key principle**: Optimal atomization at the lowest possible pressure. Excessive pressure = premature equipment failure + excessive overspray + poor finish.

### Filter Mesh by Tip Size

| Filter Mesh | Description | Compatible Tip Orifice | Materials |
|------------|-------------|----------------------|-----------|
| 200 mesh | Red (very fine) | 0.007-0.013" | Lacquers, stains, solvents |
| 100 mesh | Blue (fine) | 0.013-0.015" | Enamels, oil-based |
| 60 mesh | Black (medium) | 0.015-0.025" | Latex paints, primers |
| 30 mesh | Gray (coarse) | 0.025"+ | Block fillers, elastomerics |

### 3. Masking-to-Spray Labor Ratio

**Standard ratio: 3:1 to 4:1** (masking hours to spray hours)

For a 2,000 SF exterior:
- Spray application (2 coats): ~15-20 man-hours (2 technicians)
- Prep + masking: ~30-50 man-hours
- Architecture complexity is primary variable (simple ranch vs. Victorian with many panes)

### 4. Overspray Management

#### Wind Limits

| Wind Speed | Status | Action |
|-----------|--------|--------|
| 0-2 mph | Caution | Paint fog lingers — can be problematic |
| 2-9 mph | Optimal | Light breeze disperses fog, ideal conditions |
| 10+ mph | Stop | Halt all spray operations |

#### Application Technique
- **Gun distance**: 10-12 inches from substrate (standard)
  - Too close: bounce-back
  - Too far (18"+): dry spray texture, increased drift
- **Gun angle**: Perpendicular (90 degrees) to surface — "arcing" causes uneven distribution
- **Overspray drift**: Atomized particles (as small as 5 microns) can travel hundreds of feet

#### Masking Layers
- Static-cling plastic sheeting for windows/glass doors
- Handheld aluminum spray shields (24-48") for edge cutting
- Hose management to prevent dragging across wet surfaces

### 5. Spray Production Rates

| Surface Type | Production Rate (SF/hr) | Notes |
|-------------|------------------------|-------|
| Open siding runs (lap/fiber cement) | 300-500 | 517 tip, clear work path |
| Masonry/stucco (spray only) | 300-400 | Raw spray speed |
| Masonry/stucco (spray + back-roll) | ~150-200 | Second technician following |
| Exterior trim | 100-150 | Constant repositioning, precision required |

### 6. Back-Roll Protocol

#### Mandatory Back-Rolling
- **Stucco and porous masonry**: Spray bridges over pinholes/voids; back-rolling forces coating into pores for continuous protective film
- **Weathered wood siding**: Open grain requires mechanical working of primer/paint into fibers for adhesion
- **T-1-11 and rough-sawn siding**: Deep vertical grooves need roller to distribute paint

#### Optional / Discouraged
- **Fiber cement (Hardiplank)**: Back-rolling introduces unwanted stipple/orange peel — spray-only for factory-smooth finish
- **Vinyl siding**: Spray-only for clean industrial lines
- **Metal doors**: Spray-only for smooth finish

### 7. Material Consumption: Spray vs. Manual

| Application Method | Transfer Efficiency | Material Impact |
|-------------------|--------------------|-----------------|
| Manual rolling | ~95% | Baseline |
| Airless spray | 50-70% | 25-33% more material than brush/roll |
| HVLP spray | 65-90% | 10-35% loss |

**Example**: 2,500 SF home — spray requires ~55 liters vs. ~38 liters hand-applied.

**DFT note**: Spray applies 2-3 mils wet per pass vs. 4-5 mils for brush/roller. Two spray coats typically required even when visual coverage appears in one.

**Machine priming**: ~1 liter of paint required just to prime a standard machine with 50-foot hose.

### 8. Whole-House Spray Sequencing

**Logic: Top-Down, Broad-to-Narrow**

| Step | Surfaces | Rationale |
|------|----------|-----------|
| **1. High-elevation details** | Soffits, fascia, gutters | Drips fall on unpainted surfaces below |
| **2. Corner banding** | Inside corners sprayed vertically | Saturate corners before horizontal runs |
| **3. Main body (siding)** | Horizontal passes, top course down to foundation | Maintains wet edge, gravity-assisted |
| **4. Trim and accent** | Two approaches (see below) | Method depends on crew preference |
| **5. Doors and hardware** | Entry doors (often removed), shutters (removed) | High-touch, last painted |

#### Trim Sequencing: Two Schools

| Approach | Method | Advantage |
|----------|--------|-----------|
| **Trim-First** | Spray all trim, let dry, mask trim, spray body | Easier to mask 4" trim board than 20' wall |
| **Body-First** | Spray body, hand-brush trim last | Sharper trim finish, avoids massive body masking |

## Part B: Brush, Roll, and Hybrid Application Methods

### 1. Method Selection Criteria

| Factor | Spray | Roller | Brush |
|--------|-------|--------|-------|
| **Primary mechanism** | Hydraulic atomization | Mechanical transfer | Precision contact |
| **Transfer efficiency** | 40-70% | 90-99% | 95-99% |
| **Optimal projects** | Large-scale, new build | Residential, occupied | Trim, details, small areas |
| **Setup intensity** | High (extensive masking) | Moderate | Low |
| **Finish profile** | Ultra-smooth/factory-like | Textured/stippled | Traditional/roped |
| **Weather sensitivity** | High (wind/humidity) | Moderate | Low |

#### When to Choose Brush-and-Roll Over Spray
- Projects under 500-750 SF (masking negates spray speed advantage)
- Occupied residential (overspray risk to furnishings, vehicles, neighbors)
- Wind conditions above 10 mph
- Dense residential areas with insufficient containment boundaries
- Substrates requiring mechanical working (weathered wood, rough-sawn)
- High-end trim work requiring Level 4 PCA finish

### 2. Brush Techniques for Exterior Details

#### Trim, Fascia, and Window Casings
- Fascia: Cut in top edge at roofline with 2-2.5" nylon/polyester brush, complete face with brush or small roller
- Window sashes: Start from inner parts, work outward
- Paneled doors: Recessed panels first, then stiles (middle, top, center, bottom), then vertical edges

#### Cutting In
- 1.5-2" angled sash brush
- Dip ~2" into paint, slap against bucket to remove excess
- Hold like pencil, bristles edgewise to line
- "Wiggle" into corners, pull along edge in 4" strokes

#### Lap Mark and Brush Mark Prevention
- Work in manageable sections — never let wet edge dry before blending
- Start each stroke in unfinished area, brush back toward finished section
- Sweep brush up and off surface to feather edges

### 3. Roller Nap Selection

| Surface Texture | Typical Substrate | Recommended Nap | Rationale |
|----------------|------------------|-----------------|-----------|
| Very smooth | Metal doors, plaster, sanded wood | 3/16-1/4" | Minimizes stipple; high-gloss finishes |
| Smooth | Drywall, new wood siding, trim | 3/8-1/2" | Versatile; standard residential |
| Semi-smooth | Textured walls, decks, concrete | 1/2" | Higher paint capacity for light textures |
| Semi-rough | Stucco, rough wood, shingles | 3/4" | Reaches into deep grain and valleys |
| Rough | Heavy stucco, popcorn ceilings | 1" | Forces paint into high-profile irregularities |
| Very rough | Brick, concrete block, fences | 1-1/4 to 1-1/2" | Maximum load; saturates porous masonry |

#### Roller Cover Materials
- **Nylon/polyester blend**: Standard for water-based latex
- **Natural fiber (lamb's wool)**: Preferred for oil-based coatings
- **Woven covers**: Very smooth finishes
- **Knit covers**: High-production, heavy film build
- **Microfiber blend**: High-capacity load, smooth release
- **Foam**: Small detail work, glossy-smooth finishes only

#### Roller Technique
- 12-18" rollers on extension poles for production
- "W" or "M" pattern to distribute, then vertical strokes to level the film

### 4. Production Rates Comparison

| Application Method | Production Rate (SF/hr) | Best For |
|-------------------|------------------------|----------|
| Airless spray | 500-2,000 | Large open surfaces (>1,000 SF) |
| Roller | 150-400 | Medium surfaces, residential |
| Brush | 50-100 | Trim, details, small touch-ups |

**Break-even**: Spraying becomes cost-effective above 750-1,000 SF when masking labor is factored in.

### 5. Material Consumption Comparison

| Application System | Transfer Efficiency | Material Loss |
|-------------------|--------------------|--------------|
| Brush/roller | 90-99% | Negligible |
| Airless spray | 40-70% | 30-50% |
| HVLP spray | 65-90% | 10-35% |
| Electrostatic spray | 70-95% | <5-30% |

#### Coverage Rates by Substrate (per gallon)

| Surface Material | Coverage (SF/gal) | Expected Coats | Notes |
|-----------------|-------------------|----------------|-------|
| Vinyl siding | 350-400 | 1-2 | Non-absorbent, smooth |
| Smooth wood siding | 300-350 | 2 | Moderate absorption |
| Aluminum siding | 300-400 | 2 | Non-absorbent |
| Fiber cement | 300-350 | 2 | Sits on surface |
| Stucco | 150-250 | 2 | Highly porous and textured |
| Brick/masonry | 150-200 | 2-3 | Very absorbent |
| Rough wood/shingles | 200-300 | 2-3 | Grain absorbs heavily |

### 6. Back-Brushing and Back-Rolling Requirements

| Surface | Back-Roll/Brush Required? | Method | Reason |
|---------|--------------------------|--------|--------|
| Stucco/masonry | **Mandatory** | 3/4-1" nap roller | Force paint into pores, prevent holidays |
| Weathered wood siding | **Mandatory** | Back-brush or back-roll | Work paint into open grain for adhesion |
| T-1-11 / rough-sawn | **Mandatory** | Roller | Deep grooves need mechanical distribution |
| Wood stain applications | **Mandatory** | Back-brush | Scrub stain into fibers for UV/rot protection |
| Deck stain | **Mandatory** | Back-brush with applicator pad | Penetration critical on horizontal surfaces |
| Fiber cement | **Avoid** | Spray only | Back-rolling introduces unwanted texture |
| Vinyl siding | **Avoid** | Spray only | Stipple ruins factory-like finish |
| Metal doors | **Avoid** | Spray only | Orange peel from roller is undesirable |

### 7. Method Selection by Quality Tier and Condition

| Quality Tier | Walls/Siding | Trim | Doors |
|-------------|-------------|------|-------|
| **Standard (PCA Level 2)** | Spray + back-roll on porous; spray-only on smooth | Spray or brush | Spray or brush/roll |
| **Premium (PCA Level 3)** | Spray + back-roll; brush-and-roll on occupied homes | Brush for precision | Spray (removed from hinges) |
| **Supreme (PCA Level 4)** | Spray for smoothness; brush-and-roll for wall imperfections | Spray + hand-sand between coats | Spray (removed, controlled environment) |

### 8. Pros and Cons Summary

| Method | Pros | Cons |
|--------|------|------|
| **Airless spray** | Fastest (3-5x); reaches complex profiles; factory-smooth finish; best for large scale | 30-50% material waste; extensive masking; wind-sensitive; setup overhead |
| **Roller** | 90%+ transfer efficiency; good production speed; moderate setup; textured finish | Stipple/orange peel on smooth surfaces; slower than spray; limited on complex profiles |
| **Brush** | Highest precision; best adhesion (mechanical working); minimal waste; low setup | Slowest method; visible brush marks possible; labor-intensive on large surfaces |
| **Spray + back-roll** | Combines speed with adhesion; best for porous substrates | Requires 2-person crew; coordination critical |
| **Spray + back-brush** | Best for stain penetration; combines speed with fiber-level working | Requires 2-person crew; timing-critical (must back-brush while wet) |

## PaintFactor Integration Notes

### Application Method Dimension
This doctrine defines the application method values for exterior specs:
- `spray` — airless spray only (smooth, non-porous substrates)
- `spray_backroll` — spray with mandatory back-rolling (stucco, masonry, weathered wood)
- `spray_backbrush` — spray with mandatory back-brushing (stain applications)
- `brush_roll` — traditional brush and roll (small projects, occupied, high wind)
- `brush` — brush only (trim, cutting-in, detail work)

### Production Rate Keys
- `RATE_SPRAY_SIDING` = 300-500 SF/hr
- `RATE_SPRAY_MASONRY` = 300-400 SF/hr (spray only), 150-200 SF/hr (spray + back-roll)
- `RATE_SPRAY_TRIM` = 100-150 SF/hr
- `RATE_ROLL_SIDING` = 150-400 SF/hr
- `RATE_BRUSH_TRIM` = 50-100 SF/hr

### Material Consumption Modifiers
- `MOD_MATERIAL_SPRAY` = +25-33% over brush/roll baseline
- `MOD_MATERIAL_POROUS` = higher consumption (stucco 150-250 SF/gal vs. smooth 300-400 SF/gal)

### Masking Labor
- Masking-to-spray ratio: 3:1 to 4:1
- Must be estimated as separate line item, not embedded in production rate

### Tip Selection Logic
- Map substrate type to tip code table
- Pair tip orifice with correct filter mesh
- Track tip wear by gallon count (replace at 15-40 gal for latex)

### Back-Roll Decision Logic
- If substrate in [stucco, masonry, weathered_wood, rough_sawn, T1-11]: back_roll = mandatory
- If substrate in [fiber_cement, vinyl, metal]: back_roll = avoid
- If coating_type = stain: back_brush = mandatory
