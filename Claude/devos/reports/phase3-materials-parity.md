## DISPOSITION (reviewed 2026-06-22, post mapping-fix `144a5689` + cutover `69b46c26`)
Regenerated after the scenario→spec mapping fix moved ~82 scenarios out of "no-spec" into the comparison (so counts rose from the Task-3 snapshot of 17 regressions / 88 no-spec). **All 69 "regressions" are FALSE** — every one is the scenario array correctly OMITTING a role the catalog matcher over-emits. By category:
- **Already-primed from-states** (`*_FROM_PRIMED_FACTORY`, `*_FROM_PRIMED`, `*_PRIMED_*`, and the primed-state `SCN_ARCH_ELEMENT_PAINT_*` / `SCN_WAINSCOT_PAINT_*`): array drops the primer because the substrate is already primed — correct; the matcher over-emits a primer family-wide ignoring from-state.
- **Stain scope** (`*_STAIN_ONLY`, `*_CLEAR_ONLY`, `*_FROM_STAINED`): array carries only the in-scope stain/sealer/clear role; the matcher emits all three regardless — array correct.
- **`SF_DOOR_FRAME_NC_FINISH`** (2): matcher mis-emits `SYS_FF_GALLERY` (a finish system) under the primer role; the array correctly has no primer — array is MORE correct.
- **`SF_WINDOW_INT_NC` factory-wood** (1): matcher picks an aluminum DTM primer on a wood window; array omits — array correct.
- **Representative-grain note (spec-deferred):** `SCN_ARCH_ELEMENT_PAINT_*` / `SCN_WAINSCOT_PAINT_*` are the primed-state variants (finish-only arrays); their bare siblings (`SCN_ARCH_ELEMENT_NC_QT3_*_FROM_BARE`, array carries `SYS_ARCH_PRIMER_STUB`) carry the primer. In a project mixing bare AND primed arch/wainscot across rooms, the family's single first-fired representative could be the primed one, dropping the BARE substrate's primer line (finish still emits — nothing goes material-less). This is the per-fired-scenario-grain limitation the spec explicitly defers, NOT a selection bug.

**No-spec (6) — all intentional:** 4× `SCN_COMBINED_*` (combined pass-group scenarios, no `paintable_item`) + 2× legacy `SCN_INT_DOOR_FRAME_STAIN_CLEAR` / `SCN_INT_DSST_STAIN_CLEAR` (reference nonexistent `SYS_INT_*`; no `SF_DOOR_*_STAIN` spec exists — author-or-archive in Phase 3b).

**Corrections (420) + Changed-system (140):** accepted — the array supplies materials the matcher emitted nothing for (mostly families with no own catalog → stub systems) or picks the authored system over the matcher's hardcoded-sheen guess.
