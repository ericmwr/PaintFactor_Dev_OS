# Window Systems Painting Doctrine

**Status:** Canonical  
**Version:** 1.1  
**Last Updated:** 2026-01-28  
**Source:** NotebookLM Research Report  
**Aligned With:** PaintScope Window Counting System Specification

This document establishes technical standards for professional architectural coating of residential window systems. All window painting specifications must comply with this doctrine.

---

## 1. Introduction and Scope

Window painting represents one of the most technically demanding segments of architectural finishing. Unlike broad wall surfaces, windows are complex mechanical assemblies composed of diverse substrates requiring specialized preparation and application protocols.

### 1.1 Governing Standards

All window painting specifications shall comply with:
- **PCA** (Painting Contractors Association) Industry Standards P1 through P25
- **AAMA** (American Architectural Manufacturers Association) performance specifications for metallic substrates
- **SSPC/NACE** surface preparation standards for steel substrates

### 1.2 Definition of Properly Painted Surface

Per PCA/FCA unified standards, a properly painted surface exhibits uniform appearance in color, texture, hiding, and sheen. The film shall be virtually free of foreign material, lumps, skins, runs, sags, holidays, and misses. Surrounding environment shall be free of drips, spatters, spills, or overspray.

#### 1.2.1 Inspection Protocol

| Criterion | Requirement |
|-----------|-------------|
| Distance | 39 inches (1 meter) minimum |
| Magnification | None |
| Lighting | Finished lighting conditions (as occupied) |
| Position | Normal viewing position (eye level) |

## 3. Wood Window Systems

Wood remains predominant in high-end residential construction due to thermal efficiency and aesthetic versatility. Its hygroscopic nature requires careful moisture management to prevent dimensional instability and biological decay.

### 3.1 Moisture Requirements

| Application | Moisture Content |
|-------------|------------------|
| Maximum before painting | 19% MC |
| Interior joinery (heated) | 6% to 8% MC |
| Exterior envelope | 9% to 14% MC |

#### 3.1.1 Testing Methods

- **Pin-type meters:** Measure electrical resistance at depth
- **Pin-less meters:** Non-destructive surface readings
- **Pencil test:** For "dozy" wood (soft/rotting fibers), determines decay depth

Soft or rotted wood must be removed and replaced with new timber sections or professional joiner splices before painting can proceed.

### 3.2 Sanding Sequence

**Golden Rule:** Never skip more than one grit in a sequence. This ensures scratches from the previous grit are effectively leveled.

| Stage | Grit | Purpose |
|-------|------|---------|
| Initial Stripping | 60-80 | Heavy removal of failed/peeling paint, thick varnish |
| Smoothing | 100-120 | Leveling surface, removing post-strip imperfections |
| Pre-Primer | 150-180 | Smoothing grain for initial coating (polyurethane/enamel) |
| Final Surface Prep | 220 | Final sand of bare wood before primer (QT4 and up) |
| Between-Coat Scuff | 320 | Smoothing primer/first coat; removes raised fibers (QT4 and up) |

#### 3.2.1 Wood Species Considerations

- **Softwoods (pine, alder):** Start at 120 grit, finish at 220 (water-based) or 180 (oil-based)
- **Hardwoods (oak, maple):** Final sand at 150-180 grit to prevent burnishing

## 4. Muntin and Glass Interface Techniques

Muntins (narrow wood strips separating panes) represent the most labor-intensive window painting component, requiring both precision and weather-sealing strategy.

### 4.1 The 1/16-Inch Seal Technique

Professional contractors apply paint slightly onto the glass pane by approximately 1/16 inch. This is not a mistake but a functional requirement that creates an airtight seal between glass and wood/glazing putty, preventing moisture infiltration and premature rot.

#### 4.1.1 Execution Protocol

1. Cut in paint overlapping glass by 1/16 inch
2. Allow paint to fully dry
3. Score a straight line on glass using sharp razor blade with putty knife guide
4. Scrape away excess paint from glass

### 4.2 Liquid Masking Technology

Liquid masking agents (e.g., Masking Liquid H2O, Jasco Mask & Peel) provide significant efficiency gains for multi-pane Colonial-style windows.

#### 4.2.1 Application Process

1. Apply liquid mask liberally to glass and sash parts (acts as primer for wood, peelable film for glass)
2. Paint topcoats directly over mask and frame
3. Once dry, score edge of glass with utility knife
4. Peel mask away for crisp line and clean glass

**Limitation:** Avoid liquid masks on weathered, dry wood which requires deep-penetrating oil-based primer.

## 5. Vinyl and PVC Window Systems

Vinyl (uPVC) is a thermoplastic sensitive to heat absorption. Dark exterior colors can cause warping, buckling, and insulated glass seal failure without proper coating technology.

### 5.1 Light Reflectance Value (LRV) Requirements

**Standard Practice:** Only colors with LRV ≥ 55 should be applied to vinyl frames.

Dark colors (low LRV) absorb solar energy, raising substrate temperature beyond structural limits.

#### 5.1.1 Vinyl-Safe Technology

For dark colors (black, deep bronze), use vinyl-safe paint lines with heat-reflective pigments that reflect infrared radiation while appearing dark to visible spectrum:

- Sherwin-Williams Emerald Urethane Trim Enamel (vinyl-safe color deck)
- Benjamin Moore Aura Exterior (vinyl-safe colors)

### 5.2 Adhesion Protocol for Non-Porous Polymers

1. **Cleaning:** TSP substitute or mild detergent, followed by 70%-91% isopropyl alcohol wipe to eliminate silicone residues
2. **Etching:** Light scuff-sand with 220-grit to create micro-tooth for primer
3. **Priming:** Adhesive bonding primer rated for vinyl/PVC (INSL-X STIX, Sherwin-Williams Extreme Bond)

## 6. Metal Window Systems

Metal windows (aluminum and steel) require specialized preparation protocols to manage oxidation, ensure proper adhesion, and provide long-term corrosion protection.

### 6.1 General Metal Preparation

All metal substrates require thorough degreasing before any mechanical or chemical preparation. Use BC-7000 or equivalent heavy-duty alkaline cleaner to remove oils, greases, and manufacturing residues.

### 6.2 Aluminum Window Systems

Aluminum windows are common in both residential and commercial applications. While aluminum does not rust, it forms aluminum oxide which can interfere with coating adhesion.

#### 6.2.1 Chemical Pre-treatment

- Concentrated alkaline solutions may act as etchants for primer adhesion
- Organofunctional silanes and organometallic compounds (zirconium/titanium-based) create chemical bonds between metal surface and paint resin
- Phosphoric acid-based treatments create zinc phosphate coating for improved adhesion

#### 6.2.2 AAMA Performance Specifications

| Specification | Target Use | Weathering | Performance |
|---------------|------------|------------|-------------|
| AAMA 2603 | Interior/Low-Exposure | 1 Year South FL | Slight fade/chalk resistance |
| AAMA 2604 | High-Performance | 5 Year South FL | 30% gloss; <5 Delta E fade |
| AAMA 2605 | Superior Performance | 10 Year South FL | 50% gloss; <5 Delta E fade |

**Recommended Product:** Polane Solar Reflective Polyurethane Enamel for industrial-grade UV and mar resistance.

### 6.3 Steel Window Systems

Steel windows are found in historic properties, industrial-style architecture, and commercial crossover applications. Unlike aluminum, steel is subject to rust (iron oxide formation) which requires active management.

#### 6.3.1 Rust Assessment Protocol

| Rust Grade | Description | Treatment Approach |
|------------|-------------|-------------------|
| Surface Rust | Light orange discoloration, no pitting | Mechanical removal + rust-inhibitive primer |
| Scale Rust | Flaking rust layers, slight surface texture | Power tool cleaning + rust converter + primer |
| Pitting Rust | Visible pits in metal surface | Fill pits with epoxy filler + primer system |
| Structural Rust | Through-rust, holes, compromised integrity | Cut out and replace affected sections |

#### 6.3.2 SSPC Surface Preparation Standards

| Standard | Method | Result |
|----------|--------|--------|
| SSPC-SP1 | Solvent Cleaning | Remove oil, grease, dirt (always first step) |
| SSPC-SP2 | Hand Tool Cleaning | Remove loose rust, paint, scale with scrapers, wire brushes |
| SSPC-SP3 | Power Tool Cleaning | Same as SP2 using power tools; more thorough |
| SSPC-SP11 | Power Tool to Bare Metal | Remove all rust except in pits; 1 mil profile |

#### 6.3.3 Rust Treatment Methods

- **Mechanical Removal:** Wire brushes, scrapers, power sanders, needle guns. Remove all loose and flaking rust. Tight rust may remain for converter treatment.
- **Chemical Conversion:** Phosphoric acid-based products (Ospho, POR-15 Metal Prep, Rust-Oleum Rust Reformer) convert iron oxide to stable iron phosphate. Product turns black when conversion complete.
- **Encapsulation:** For stable, tightly-adhered rust that cannot be fully removed, rust-encapsulating primers seal rust from oxygen and moisture.

#### 6.3.4 Primer Requirements for Steel

- **Rust-inhibitive primers:** Contain zinc, red oxide, or other corrosion inhibitors
- **DTM (Direct-to-Metal) primers:** Sherwin-Williams Pro Industrial DTM, Rust-Oleum Professional
- **Zinc-rich primers:** For severe environments, galvanic protection

**Flash Rust Prevention:** In humid conditions, bare steel can flash rust within hours. Apply primer immediately after preparation, or use flash-rust inhibiting primers.

#### 6.3.5 Topcoat Considerations

- Oil-based or alkyd enamels: Traditional choice, excellent adhesion to primers
- DTM acrylic enamels: Lower VOC, faster dry, good durability
- Polyurethane enamels: Maximum durability for high-traffic or exterior exposure

## 7. Window Quantification Methods

Window quantification drives labor estimation, material calculation, trim takeoffs, and wall deductions. PaintFactor uses the **Size Bucket Method** as the default approach, with the traditional Opening Count Method available as a legacy alternative.

### 7.1 Size Bucket Method (Default)

The Size Bucket Method eliminates the need for window measurement during walkthrough. Estimators visually categorize windows into four groups based on approximate perimeter.

| Bucket | Label | Perimeter (LF) | Derived Area (SF) | Visual Reference |
|--------|-------|----------------|-------------------|------------------|
| S | Small | 8 | 4 | Bathroom, basement, transom |
| M | Medium | 12 | 9 | Standard bedroom, living room |
| L | Large | 17 | 18 | Picture windows, wide double units |
| O | Oversized | Measured | P²÷16 | Requires tape measure |

#### 7.1.1 Area Derivation Formula

```
Area = Perimeter² ÷ 16
```

This formula assumes a roughly square aspect ratio, which produces conservative deductions (slightly underestimates area). For material estimation, this builds in a safety buffer.

### 7.2 Perimeter-First Math Rationale

The Size Bucket Method uses perimeter as the universal unit of capture. This architectural decision provides several advantages:

- Perimeter (LF) drives trim calculations directly — no conversion needed
- Area derives from perimeter for wall deductions using P²÷16
- Eliminates need for separate width/height measurements
- Estimator counts windows visually by size bucket — no tape measure for 95% of windows
- Single capture produces: trim LF, wall deduction SF, and window counts

### 7.3 Opening Count Method (Legacy)

The traditional Opening Count Method counts windows based on equivalent openings. This method is retained for legacy estimates and specific client requirements.

#### 7.3.1 Dimensional Adjustments

Windows are not counted as simple "1 opening" units. For wood windows: count 1 opening per 6 square feet of window area.

**Example:** A standard 6 SF window = 1 opening; a 24 SF picture window = 4 openings

#### 7.3.2 Complexity Multipliers

| Window Type | Opening Value | Rationale |
|-------------|---------------|-----------|
| French Doors/Windows | 1.5 openings | Divided lights |
| Dutch Doors | 2.0 openings | Split configuration |
| Paneled (vs. Flush) | 1.25 openings | Panel detailing |

#### 7.3.3 Method Limitations

- Designed primarily for interior paint-grade work
- Exterior doors require separate per-door method for weatherproofing systems
- Oddly shaped windows or window walls may require reversion to SF calculations

### 7.4 Trim Package Options

Trim package determines which trim-related tasks and specs apply to a window group.

| Package | Components Included | Typical Use |
|---------|---------------------|-------------|
| None | Window not being painted (wall deduction or mask only) | Vinyl windows not in scope; unpainted openings |
| Casing | Interior trim/casing only | Casing treatment only |
| Jamb | Extension jamb only | Jamb treatment only |
| Casing and Jamb | Casing and extension jamb | Combined casing and jamb treatment |
| Full Pkg | Casing + stool + apron | Full interior window treatment |

## 8. Application Methodology

### 8.1 Window Types

PaintFactor recognizes five primary window operation types, each with distinct labor implications:

| Type | Description | Labor Notes |
|------|-------------|-------------|
| Double-hung | Two vertically sliding sashes | Standard baseline; multiple operable parts |
| Casement | Side-hinged, crank-operated | Similar to DH; often easier access to both sides |
| Slider | Horizontally sliding sashes | Similar to casement; horizontal tracks may need cleaning |
| Fixed | Non-operable, picture window | Simplest — frame and trim only, no operable parts |
| Awning | Top-hinged, opens outward | Access can be awkward; similar to casement labor |

### 8.2 Brush vs. Spray Decision Framework

#### 8.2.1 Manual Brushing

- Provides unparalleled control for detailed trim and muntins
- 1.5-inch angled sash brush works paint into grain and complex profiles
- Labor-intensive; may leave brush marks/texture

#### 8.2.2 Spray Systems (HVLP/Air-Assisted Airless)

- Factory-like smooth finish; significantly faster for large surfaces
- **Waste Factor:** 20%-40% material waste from overspray and box method (50% overlap)
- Requires extensive masking and containment

### 8.3 Productivity Metrics

| Window Type | Base Labor Factor | Notes |
|-------------|-------------------|-------|
| Double-Hung | 1.10-1.25 hrs/EA | Standard prep and two coats |
| Casement | 1.10 hrs/EA | Similar to DH; easier access |
| Slider | 1.10 hrs/EA | Horizontal operation; track cleaning |
| Fixed | 0.90 hrs/EA | No operable parts — frame/trim only |
| Awning | 1.15 hrs/EA | Awkward access angle |
| Multi-pane (any type) | Base × 1.20 | +20% for muntin complexity (Resene) |
| Windowsills | 0.06 hrs/LM | Linear measurement for horizontals |

*Note: Multi-pane/Colonial is a modifier that applies to any base window type, not a separate type.*

### 8.4 Height Tier Modifiers

Height modifiers apply to base labor rates based on access difficulty. PaintFactor uses a 5-tier system aligned with the Production Rate Reference:

| Code | Tier | Height Range | Modifier | Access Method |
|------|------|--------------|----------|---------------|
| HT_STD | H1 | 0-8 ft | 1.00x | Ground / step stool |
| HT_STEP | H2 | 9-12 ft | 1.30x | Step ladder / extension ladder |
| HT_EXT | H3 | 13-17 ft | 1.50x | Extension ladder |
| HT_SCAFFOLD | H4 | 18-24 ft | 2.00x | Scaffolding |
| HT_LIFT | H5 | 25+ ft | 2.50x | Lift equipment |

Height modifiers are applied multiplicatively to base labor rates.

**Example:** A Double-Hung window at H3 (13-17 ft): 1.15 hrs × 1.50 = 1.725 hrs

### 8.5 Condition Modifiers

Condition modifiers apply to **prep tasks only**, not finish coats. This reflects that poor condition increases prep labor while finish application remains consistent.

| Condition | Description | Prep Modifier | Finish Modifier |
|-----------|-------------|---------------|-----------------|
| Good | Clean, intact finish; minor cleaning only | 1.00x | 1.00x |
| Fair | Minor weathering, spot repairs needed | 1.50x | 1.00x |
| Poor | Peeling, rot, glazing failure | 2.00x | 1.00x |

*Note: Windows in Poor condition within an otherwise Good group should be flagged as exceptions for detailed scoping and crew reference.*

## 9. Film Thickness and Curing

### 9.1 Film Build Requirements

Coating performance is fundamentally tied to film build. Too thin: insufficient UV blockers and protective resins. Too thick: curing failure leading to blocking or softness.

#### 9.1.1 DFT Calculation

```
DFT = WFT × (% Volume Solids)
```

**Example:** 34% volume solids at 3 mils WFT = 1.02 mils DFT

**Target System DFT:** Minimum 2.5 mils; maximum 5 mils (to prevent internal stress/cracking)

### 9.2 Measurement Tools by Substrate

| Tool | Substrate | Mechanism |
|------|-----------|-----------|
| WFT Gauge (Comb) | All (while wet) | Measures liquid depth immediately after application |
| Magnetic Induction | Ferrous Metal (Steel) | Magnetic flux change measures non-magnetic coating |
| Eddy Current | Non-Ferrous (Aluminum) | Electromagnetic induction on conductive metal |
| Ultrasonic (PosiTector) | Wood / Vinyl | Times ultrasonic pulse reflections from substrate |

## 10. Common Defects and Remediation

### 10.1 Blocking and Sticking

Occurs when freshly painted surfaces stick together when pressed (closing window before full cure).

#### 10.1.1 Causes

- Application in high humidity
- Low-quality vinyl-acrylic latex
- Insufficient cure time (often 3-7 days for enamels)

#### 10.1.2 Prevention

- Use 100% acrylic or urethane-enriched enamels
- Paint sashes in "ajar" position
- Avoid painting sliding pulley stiles or meeting rails

#### 10.1.3 Remediation

Sand to dull finish, prime with high-block-resistant primer, repaint.

### 10.2 Bridging and Pinholing

- **Bridging:** Coating spans a gap without filling it, creating hollow void that eventually cracks. Caused by excessive paint viscosity or improper technique.
- **Pinholing:** Tiny blisters from trapped air, solvent, or moisture escaping during cure. Caused by inadequate substrate cleaning, ignoring flash-off times, or application in direct intense sunlight.

### 10.3 Metallic Coating Defects

Bleeding or shading in metallic/pearlescent finishes caused by uneven orientation of aluminum flakes.

#### 10.3.1 Solutions

- Maintain consistent spray distance
- Use faster-evaporating thinners in cold conditions
- Thoroughly mix metallic pigments

## 11. Lead RRP Compliance

For residential structures built before 1978, the EPA Renovation, Repair, and Painting (RRP) Rule governs window projects. Window work is categorized as high-risk due to friction surfaces (sashes sliding in frames) being major lead dust generators.

### 11.1 Lead-Safe Work Practices

#### 11.1.1 Required Protocols

1. **Notification:** Provide "Renovate Right" pamphlet to owner at least 7 days prior to work
2. **Containment:** Interior areas sealed with plastic; exterior protection extends 10 feet from building with wind protection
3. **Cleanup:** HEPA vacuum and wet-mop sequence, followed by clearance dust-wipe test by licensed inspector

#### 11.1.2 Prohibited Acts

- Open-flame torches
- Heat guns above 1100°F
- Power-sanding without HEPA vacuum attachment

### 11.2 VOC Compliance

Modern window coatings must comply with regional VOC regulations (e.g., SCAQMD in California). High-performance water-based urethanes provide alkyd durability with lower environmental impact and faster return-to-service times.

## 12. Lifecycle Management

### 12.1 Climate-Based Considerations

#### 12.1.1 Coastal Environments

- Most severe conditions: salt spray, high humidity, UV exposure
- Application window: late spring through early fall only
- Inspect every 2 years; rinse annually with fresh water

#### 12.1.2 Southwest/Desert

- Extreme thermal cycling (10°F-20°F swings in hours)
- Requires flexible or elastomeric topcoats that expand/contract without micro-cracking

### 12.2 Warranty and Recoat Intervals

- Manufacturer recommendation: exterior recoat every 2-3 years for warranty validity
- High-quality two-coat system: 7-15 years on stable substrates
- South/West-facing elevations weather faster than North/shaded elevations

## 13. PaintFactor Integration

This section defines how window specifications integrate with the PaintScope geometry capture system and the PaintFactor estimation engine.

### 13.1 Specification Structure

- Window specifications consume geometry from PaintScope (EA counts, LF measurements)
- Specs never perform geometry calculations — only key lookups
- Substrate type determines preparation protocol and primer selection
- Window style drives complexity modifiers
- Quality tier (QT3-QT6) determines coating system and production rate adjustments

### 13.2 Modifier Categories

| Category | Options | Application |
|----------|---------|-------------|
| Substrate | Wood, Vinyl/Clad, Aluminum, Steel | Drives prep protocol and primer selection |
| Condition | Good (1.0x), Fair (1.5x), Poor (2.0x) | Prep labor only |
| Style | Multi-pane +20% labor | Applied to base window type |
| Access | H1-H5 height tiers (1.00x-2.50x) | Applied to all labor |
| Lead | Pre-1978 structures | Triggers RRP protocol modifier |

### 13.3 Estimation Engine Considerations

- Size Bucket Method provides baseline for window quantification
- Oversized windows (Bucket O) use measured perimeter with P²÷16 for area
- Exterior weatherproofing requires separate calculation from interior work
- Material coverage varies significantly by application method (brush vs. spray waste factor)

### 13.4 PaintScope Output Keys

Specifications consume the following output keys from PaintScope. Specs perform key lookups only — never geometry calculations.

#### 13.4.1 Window Counts by Size

```
PS_OPENING_EA.WINDOW_S          // Small window count
PS_OPENING_EA.WINDOW_M          // Medium window count
PS_OPENING_EA.WINDOW_L          // Large window count
PS_OPENING_EA.WINDOW_O          // Oversized window count
PS_OPENING_EA.WINDOW_TOTAL      // Total all windows
```

#### 13.4.2 Derived Quantities

```
PS_OPENING_LF.TRIM_WINDOW       // Total trim linear footage
PS_OPENING_SF.WINDOW_DEDUCT     // Total wall deduction SF
```

#### 13.4.3 Height Distribution

```
PS_OPENING_EA.WINDOW_H1         // Windows at height tier 1 (0-8 ft)
PS_OPENING_EA.WINDOW_H2         // Windows at height tier 2 (9-12 ft)
PS_OPENING_EA.WINDOW_H3         // Windows at height tier 3 (13-17 ft)
PS_OPENING_EA.WINDOW_H4         // Windows at height tier 4 (18-24 ft)
PS_OPENING_EA.WINDOW_H5         // Windows at height tier 5 (25+ ft)
```

#### 13.4.4 Exceptions

```
PS_OPENING_EA.WINDOW_EXCEPTION  // Count of flagged exceptions
```

### 13.5 Spec Consumption Pattern

Examples of how specifications consume PaintScope keys:

#### 13.5.1 Window Trim Painting Spec

```
Task: Paint Window Trim
Quantity Key: PS_OPENING_LF.TRIM_WINDOW
Production Rate: 25 LF/hour (base)
Modifiers: Height tier multipliers from PS_OPENING_EA.WINDOW_H1-H5
```

#### 13.5.2 Wall Painting Spec (Deduction)

```
Task: Paint Walls
Quantity: PS_WALL_SF.PAINTABLE - PS_OPENING_SF.WINDOW_DEDUCT - PS_OPENING_SF.DOOR_DEDUCT
```

Height and condition modifiers are applied at the estimation engine level, not within individual specs.

### 13.6 Exception Handling

Flagged exceptions receive special handling in the estimation and work order workflow:

| Exception Type | Trigger | Handling |
|----------------|---------|----------|
| Poor Condition | Individual window worse than group | Additional prep tasks; location note for crew |
| Bay/Bow | Complex geometry window | No modifier — increased LF/SF applies rates appropriately |
| Oversized | Window requires measurement | Measured perimeter used instead of bucket value |
| Other | Special circumstances | Free-text note for crew reference |

**Exception Rules:**
- All exceptions require location field for crew reference
- Exception notes flow through to work orders for field crew
- Poor condition exceptions may trigger additional prep line items
