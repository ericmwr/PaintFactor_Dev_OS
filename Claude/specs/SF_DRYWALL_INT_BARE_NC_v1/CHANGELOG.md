## [0.1.0] - 2026-01-21

### Status: DRAFT (superseded by 1.0.0)

Initial draft of Interior Bare Drywall New Construction Prime spec family.

### Added

- **spec.json**: Master spec definition with 4 configuration dimensions:
  - `quality_level`: QT3, QT4, QT5
  - `surface_type`: wall, ceiling
  - `application_method`: brush_roll, spray
  - `project_phase`: pre_trim, post_trim

- **research.json**: Domain research covering:
  - Drywall porosity and joint compound differential absorption
  - PVA vs high-build primer selection
  - Application method considerations
  - Common failure modes (flashing, peeling, holidays)

- **sop_modules.json**: 7 modular SOP blocks with 14 atomic tasks:
  - Surface prep (dusting)
  - Wall priming (roller and spray variants)
  - Ceiling priming (roller and spray variants)
  - Inspection and touch-up (QT4/QT5)
  - Post-prime sanding (QT4/QT5)

- **materials.json**: Material systems and consumables:
  - PVA primer system (standard)
  - High-build primer system (QT5 option)
  - Coverage profiles for bare drywall (300-400 SF/gal)
  - Consumable usage models (rollers, brushes, spray tips, sandpaper)

- **production.json**: Production rates and modifiers:
  - Task rates by UOM (SF/hr, LF/hr)
  - Time multipliers for height, access, environment conditions
  - Combined operation rates for spray+backroll (2-person crew)

- **qa_report.json**: Critic review with doctrine checks

### Key Design Decisions

1. **Spray requires wet-on-wet backroll**: Dry rolling of sprayed primer on bare drywall is NOT permitted. Backroll must occur while primer is still wet.

2. **Project phase dimension**: Pre-trim vs post-trim significantly affects EdgeLF and cut-in complexity. Separate cut-in tasks for each phase.

3. **Primer only scope**: This spec covers priming ONLY. Topcoat application is a separate spec family to allow independent configuration.

4. **Wall/ceiling separation**: Separate modules and paintable items for walls vs ceilings due to different production rates and access requirements.

5. **Factor modifiers as time multipliers**: All modifiers expressed as time multipliers (>1.0 = more time required) for consistency.
